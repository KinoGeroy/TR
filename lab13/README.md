# Лабораторная работа №13 — Обработка временных рядов  
### ежедневные продажи магазина

## 📌 Описание проекта
Проект посвящён анализу и прогнозированию временных рядов на основе реального датасета **Retail Sales Dataset**.  
В ходе работы выполняются:

- предобработка данных,
- исследование временного ряда,
- декомпозиция (тренд, сезонность, остатки),
- анализ автокорреляции (ACF, PACF),
- построение моделей прогнозирования ARIMA и Prophet,
- оценка качества прогноза,
- визуализация результатов.

Проект выполнен в формате Jupyter Notebook:  
**`lab13_time_series_sales.ipynb`**

---

## 📊 Используемый датасет
В проекте используется один из двух источников:

- **Если в папке есть файл `time_series_data.csv`**, он используется в качестве входных данных.  
- **Если файла нет**, автоматически загружается открытый датасет:
  
  👉 https://media.geeksforgeeks.org/wp-content/uploads/20240704211146/retail_sales_dataset.csv

Из исходных данных агрегируется временной ряд:

date — дата (дневная частота)
value — суммарная дневная выручка магазина

📈 Основные этапы анализа
1. Предобработка данных
заполнение пропусков (fillna(0) для продаж),

приведение к равномерной частоте,

сглаживание (скользящее среднее).

2. Исследование временного ряда
визуализация исходного ряда,

оценка статистических характеристик,

поиск тренда и сезонности.

3. Декомпозиция
Выполняется разложение на:

тренд,

сезонность (период = 7 дней),

остатки.

4. ACF и PACF
Используются для подбора параметров:

p — AR,

d — дифференцирование,

q — MA.

5. Моделирование
🔵 ARIMA(2,1,2)
построение модели,

прогноз на тестовой выборке,

прогноз на 30 дней вперёд,

оценка RMSE.

🔴 Prophet (опционально)
обучение модели,

визуализация,

прогноз на 30 дней.

📌 Результаты
➤ Метрики качества
ARIMA RMSE: ~1006

Prophet RMSE: ~1060

ARIMA показала немного более точный прогноз на данном ряде.

➤ Особенности данных
ряд очень шумный, без ярко выраженной сезонности,

много резких скачков,

слабая предсказуемость → сложность для моделей.

➤ Прогноз
Модели дают прогноз, близкий к среднему уровню продаж (~1200–1300),
что типично для слабоструктурированных рядов.

📝 Выводы
Ряд ежедневных продаж имеет ярко выраженный шумовой характер.

ARIMA(2,1,2) лучше справилась с прогнозом, чем Prophet.

Качество прогноза ограничено из-за отсутствия сезонности и повторяемых паттернов.

Для улучшения качества можно использовать:

SARIMA с недельной сезонностью,

дополнительную информацию (праздники, акции, дни недели),

ML-модели (XGBoost, LightGBM),

нейронные сети (LSTM/GRU).
